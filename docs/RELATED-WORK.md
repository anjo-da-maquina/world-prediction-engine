# 類似する研究者・組織・公開プロジェクト

2026-10-06に公式ページを確認した比較。完全に同じ万能予測システムの実現を意味しない。

| 人・チーム | 内容 | この計画への参考 |
|---|---|---|
| Philip Tetlock / Barbara Mellers — Good Judgment Project | 世界の出来事の確率予測を集約・評価する研究 | 予測の更新、実績に基づく評価、人間の判断の活用 |
| Anthony Aguirre / Greg Laughlin — Metaculusの創始者 | 複数分野の明確な予測問題、コミュニティの集約と採点 | 問題の判定条件、予測台帳、集約モデル |
| Kalev Leetaru — GDELT | 世界のニュースからイベント・人物・場所等を構造化 | 世界の観測層、ニュースイベント収集 |
| Håvard Hegreら — VIEWS / Uppsala University / PRIO | 武力紛争を1〜36か月先まで継続予測 | 領域を限定した早期警戒、公開データと研究基盤 |
| Ezra Kargerら — ForecastBench / Forecasting Research Institute | AIの予測能力を未知の未来問題で評価し、人間と比較 | AI予測の品質評価、学習データ汚染への配慮 |

参考になる順序という私の判断:
1. Metaculusで採点できる問題の作り方を学ぶ。
2. Good Judgmentの確率更新と実績評価を参照する。
3. VIEWSの特定分野でのデータ・モデル・評価の分離を見る。
4. ForecastBenchの評価方式をAI品質管理へ取り込む。
5. GDELTは観測源として加える。ニュース量そのものを事件数とみなさない。

この計画は、確率予測・早期警戒・計算社会科学・AI予測評価の接点に位置づけられる。
QAとしての強みを活かせるのは、データの公表時点管理、再現性、評価条件、
予測の失敗記録、モデル更新時の品質確認である。分野名としてはprobabilistic forecasting、
early warning systems、computational social science、AI forecasting evaluationで探せる。
